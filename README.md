# Názvosloví – trénink

Procvičování názvosloví uhlovodíků (alkany, alkeny, alkyny, dieny) ve čtyřech krocích: doplnit vodíky, najít hlavní řetězec, očíslovat a složit název z kostiček. Příklady se generují náhodně ve třech obtížnostech.

Celá aplikace je jeden soubor `index.html`. Na iPhonu: otevři stránku v Safari → Sdílet → Přidat na plochu.
